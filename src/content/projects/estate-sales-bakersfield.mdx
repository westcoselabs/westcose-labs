<CaseStudySection id="overview" number="01" title="A home for local finds">

Estate Sales Bakersfield is an estate- and yard-sale directory built for local discovery and event publishing. Shoppers can explore public listings, while organizers build and preview events before publishing them.

The project is available as a public beta. Its repository documents the working product, its publishing workflow, and the boundaries of its test-payment environment.

</CaseStudySection>
<CaseStudySection id="context" number="02" title="Discover what’s nearby">

The public directory combines listing pages with map-based exploration. MapLibre renders the maps, OpenFreeMap supplies the map style and tiles, and Geoapify supports address lookup. Confirmed locations are stored in PostgreSQL with PostGIS.

</CaseStudySection>
<CaseStudySection id="interaction-design" number="03" title="From draft to published sale">

Organizers create an account, complete onboarding, and work on private event drafts. The builder supports location validation, sanitized media uploads, and exact previews. Approval is tied to a specific event revision so that the approved content and published listing stay aligned.

Stripe-hosted test Checkout is part of the publishing flow. Verified webhooks determine publication rather than the browser’s return URL.

</CaseStudySection>
<CaseStudySection id="technical-architecture" number="04" title="One application, clear boundaries">

The application uses Next.js App Router with strict TypeScript, Prisma, and PostgreSQL. Feature modules separate domain rules, application services, and provider integrations. Custom authentication uses opaque database sessions.

</CaseStudySection>
<CaseStudySection id="status" number="05" title="Public beta">

The README identifies the hosted site as a stable, noindex production beta and its only hosted review environment. Payments are in test mode. These details describe implemented functionality, without making claims about customer adoption or commercial results.

[Visit the beta](https://estate-sales-bakersfield.vercel.app) or [read the project on GitHub](https://github.com/westcoselabs/estate-sales-bakersfield).
