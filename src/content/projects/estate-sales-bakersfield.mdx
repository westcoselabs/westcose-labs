## What this fixture proves

- One MDX source renders at one stable URL.
- Desktop OS can frame that source inside its route-backed content window.
- Pocket OS can show it as an immediate full-screen app after a direct load.
- Normal View can present the same source as a conventional case study.
- Search engines and visitors without JavaScript still receive semantic content.
